# @carbonos/carbon-engine

Versioned rules engine and deterministic calculation engine.

- `methodologies/<code>/` metadata, parameters, equations per methodology
- `eligibility/` applicability, geography, baseline, additionality checks
- `modules/`, `tools/` supporting VMD modules and VT tools
- `equations/` generic frames; real equations live per methodology

**Hard rule:** AI never invents or edits equations.
